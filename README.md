# EFinalFront - Gestión de Vehículos

Frontend en React + TypeScript + Vite para la API [EFinal](https://github.com/Elm3rr/EFinal) (tabla `tbVehiculo`).

Permite listar, crear, editar y eliminar vehículos (placa, marca, modelo, año y color).

## Cómo ejecutar

1. Levantar primero la API EFinal (perfil **https**, `https://localhost:7245`).
2. Instalar dependencias y arrancar:

```bash
npm install
npm run dev
```

La URL de la API se configura en `src/api/vehiculos.ts` (`API_BASE`).
